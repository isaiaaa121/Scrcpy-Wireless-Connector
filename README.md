\# Scrcpy Wireless Connector V5.0.1



A Windows tool to connect Android devices wirelessly

using ADB and scrcpy.



\## Features



\- Wireless ADB connection

\- Manual pairing

\- QR code pairing (experimental)

\- Automatic scrcpy launch

\- Audio disabled by default



\## Requirements



\- Windows 10 or newer

\- Python 3

\- ADB

\- scrcpy



\## Installation



1\. Install Python 3.

2\. Install dependencies:



&#x20;  pip install -r requirements.txt



3\. Place adb.exe and scrcpy.exe

&#x20;  in the project folder.



\## Usage



Run Scrcpy-Wireless-Connector.bat.



Enable Wireless Debugging on your Android device.



Follow the instructions displayed in the terminal.
